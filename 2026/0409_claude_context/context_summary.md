## 4. 학습한 주요 기술/이론 내용

### 통계
- 사분위수(Q0~Q4), IQR, Lower/Upper Fence
- 정규분포에서 Lower Fence ≈ 0.35 percentile
- q10(하위 10%) = 0.3×LF + 0.7×Q1 → LF와 Q1의 7:3 내분점
- CDF / PPF (역함수 관계)

### PCA
- 직교대각화 기반 PCA 이해 (SVD는 추후 학습 예정)
- 공분산 행렬 C = (1/n)XX^T (n으로 나누는 것은 공분산 정의상 필수)
- T² 차트, SPE 차트, Contribution 차트

### ML/강화학습
- Random Forest: 해석력 낮음, SHAP/LIME으로 보완 가능
- MPC (Model Predictive Control): Receding Horizon 방식
- MBPO (Model-Based Policy Optimization): 짧은 horizon으로 모델 오차 제한
- Offline RL vs Online RL

### SQL
- DDL / DML / DCL / DQL / TCL 분류
- SQLD 공부 중 (2026.4.5~)

### Python/코딩
- pandas DataFrame 길이 불일치 처리: `[None] + list(array)` 방식
- CSV 저장 시 `encoding='utf-8-sig'`, `index=False` 권장
- ipykernel 설치 및 Jupyter 커널 등록
- git merge conflict 해결 (`--ours` / `--theirs`)
